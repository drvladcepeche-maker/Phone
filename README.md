# Анализ телефона

Android-приложение (Kotlin): сводка устройства, список приложений с размерами, трафиком и временем на экране,
фоновая активность, рекомендации (не трогать / можно отключить / можно удалить), снимки и сравнение,
отчёт в JSON и текст, необязательная отправка отчёта в папку `reports/` этого репозитория.

APK: Actions → Build APK → артефакт `phone-analyzer-apk`.
