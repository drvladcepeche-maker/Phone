# Анализ телефона 2

Отдельная параллельная установка обновлённого Android-приложения (Kotlin). Старое приложение с идентификатором `com.phoneanalyzer` не заменяется и не удаляется.

Новый идентификатор: `com.phoneanalyzer.next`. Отображаемое имя: «Анализ телефона 2». Версия первой установки: 1.0.0 (versionCode 1). Дальнейшие обновления этой ветки должны сохранять applicationId и использовать один постоянный ключ подписи.

APK: GitHub Actions → Build Phone Analyzer APK → артефакт `phone-analyzer-debug`; после настройки постоянной подписи также доступен `phone-analyzer-release`.

## Постоянная подпись обновлённого приложения

Для установки следующих APK поверх этой новой версии используйте один и тот же keystore. Не теряйте его и не меняйте пароль/alias. Добавьте в Settings → Secrets and variables → Actions следующие секреты репозитория:

- `PHONE_KEYSTORE_BASE64` — однострочное Base64-содержимое файла PKCS12;
- `PHONE_KEYSTORE_PASSWORD` — пароль хранилища;
- `PHONE_KEY_ALIAS` — alias ключа;
- `PHONE_KEY_PASSWORD` — пароль ключа.

Не помещайте keystore или пароли в Git.

## Серверный мост

Приложение использует закрытый Supabase Edge Function `phone-analyzer` и существующую регистрацию устройства из Termux bridge проекта contacts. Токен устройства хранится в приложении с шифрованием Android Keystore. Передача отчёта выключена по умолчанию и выполняется только после подтверждения. Сервер хранит отчёты в таблице `phone_analyzer_reports` с RLS и закрытым доступом для клиентских ролей.
